# สร้างโฆษณาจาก Studio

สถานะ: รอบแรกเขียนโค้ดแล้ว ([spec](superpowers/specs/2026-10-04-studio-ad-launch-v1-design.md), [plan](superpowers/plans/2026-10-04-studio-ad-launch-v1.md)) จำกัดที่บัญชีสกุลบาท รูปเดียว วัตถุประสงค์ traffic
ส่วนที่เหลือในแผนนี้ (วิดีโอ วัตถุประสงค์อื่น ฯลฯ) เป็นรอบถัดไป
รอเจ้าของรัน migration `20261004_ad_launch.sql` บนโปรดักชัน และทดสอบยิงจริงเอง ยังไม่ได้ยิงแอดจริง
ขั้นตอนขอสิทธิ์ที่เจ้าของต้องกดเองอยู่ใน `docs/ads-manage-permission.md` ค่า `FB_ADS_MANAGE_CONFIG_ID` อยู่ใน `.env.example` แล้วยังว่าง
ของเดิมที่ `/admin/ads` อ่านอย่างเดียวด้วย `ads_read` ยังคงอยู่ งานนี้เป็นคนละหน้า คนละสิทธิ์

## ทำไมไม่ยัดเข้าหน้าแอดมิน

หน้า `/admin/ads` ขอแค่ `ads_read` และแยก Login config ออกจากเพจ เพราะการล็อกอินธุรกิจทับสิทธิ์ทั้งชุด
การสร้างแอดต้องใช้ `ads_management` จึงต้องเป็น config ที่สาม ไม่เอามารวมกับเพจหรือกับหน้าอ่านผล
ค่าใหม่ใน env: `FB_ADS_MANAGE_CONFIG_ID` ไม่มี fallback ไป config เดิม

ทุกแอดที่สร้างได้ต้องเกิดเป็นสถานะหยุด (PAUSED) การกดเผยแพร่เป็นการยืนยันครั้งที่สอง ไม่มีปุ่มที่ยิงเงินในขั้นบันทึก

## 1. หน้าใน Studio และทางเรียก

เส้นทางใหม่ `/studio/ads` อยู่ในสตูดิโอที่มีล็อกอินอยู่แล้ว ไม่ใช่หลังบ้านที่เคยไม่มีล็อกอิน

ขั้นในหน้า

1. เลือกบัญชีโฆษณาที่เชื่อมไว้แล้ว (แถว `facebook_ads:` ใน `ins_channel_auth`)
2. เลือกเพจที่จะเป็นคนโพสต์โฆษณา
3. เลือกชนิดโฆษณา แล้วเลือกชิ้นงานที่มีอยู่ให้ตรงชนิดนั้น ไม่ใช่อัปโหลดไฟล์ใหม่
4. เลือกวัตถุประสงค์ เลือกปุ่ม Click-to-Website ใส่ลิงก์หน้าเว็บ ข้อความ งบต่อวัน และพื้นที่ (ค่าเริ่มต้นประเทศไทย)
5. บันทึกเป็นแคมเปญหยุดไว้ แล้วมีปุ่มแยกสำหรับเปิดใช้

เรียกผ่าน server action ของ Studio แบบเดียวกับงานโพสต์ ไม่เปิดเป็น API สาธารณะ
ใช้ Graph `v23.0` ตัวเดียวกับ `src/lib/ads/sync.ts`

ลำดับที่ Meta ต้องการ หนึ่งบัญชีต่อหนึ่งชุด

1. `POST /act_{id}/campaigns` วัตถุประสงค์ตามที่เลือกในหน้า ไม่ล็อกเป็นแบบเดียว
2. `POST /act_{id}/adsets` งบรายวัน พื้นที่ อายุ วางบิลแบบประทับใจ
3. อัปโหลดรูปจากโปสเตอร์ หรือวิดีโอจากคลิป แล้ว `POST /act_{id}/adcreatives` โดยปุ่มชี้ไปที่ลิงก์ที่กรอก
4. `POST /act_{id}/ads` ผูกครีเอทีฟกับชุดโฆษณา สถานะ PAUSED

ถ้าขั้นใดพัง หยุดและบอกขั้นที่พัง ไม่สร้างขั้นถัดไปทับ


## ชนิดที่เลือกได้ใน Studio

หน้า `/studio/ads` ให้เลือกชนิดก่อน แล้วฟอร์มเปลี่ยนตามชนิด ทุกชนิดยังบันทึกเป็น PAUSED

| ชนิด | ชิ้นงานที่ใช้ | ครีเอทีฟ |
| --- | --- | --- |
| รูปเดียว | โปสเตอร์หนึ่งชิ้น | รูปเดียว พร้อมข้อความและลิงก์ |
| วิดีโอ | คลิปที่เรนเดอร์จบแล้วหนึ่งชิ้น | วิดีโอ พร้อมข้อความและลิงก์ |
| คารูเซล | โปสเตอร์สองถึงสิบชิ้น เรียงลำดับได้ | แต่ละใบเป็นการ์ด มีข้อความและลิงก์ของตัวเอง |
| คอลเลกชัน | รูปปกหนึ่งชิ้น บวกโปสเตอร์อย่างน้อยสามชิ้น | ปกกับแคตตาล็อกทันที ไม่ใช่ฟีดธรรมดา |

วัตถุประสงค์ที่เลือกได้ มีสามอย่าง

| วัตถุประสงค์ | ใช้เมื่อ | สิ่งที่หน้านี้ต้องมีเพิ่ม |
| --- | --- | --- |
| ทราฟฟิก | อยากได้คนเข้าลิงก์ | ลิงก์ปลายทาง |
| ลีด | อยากได้คนทักหรือกรอกฟอร์ม | เพจสำหรับข้อความ หรือฟอร์มทันทีของเพจนั้น |
| คอนเวอร์ชัน | อยากให้ Meta ปรับจากเหตุการณ์บนเว็บ | Pixel ที่แผน Conversions API ใช้อยู่ ถ้ายังไม่มี Pixel ตัวเลือกนี้กดไม่ได้ |

ชนิดกับวัตถุประสงค์จับคู่ได้อิสระ ยกเว้นคอลเลกชันที่ต้องมีลิงก์สินค้าหรือหน้าปลายทาง จึงไม่โชว์คู่กับวัตถุประสงค์ลีดแบบฟอร์มทันที


## ปุ่ม Click-to-Website

คนกดแอดแล้วไปที่หน้าเว็บที่ตั้งไว้ ไม่เปิด Messenger

ในฟอร์มมีช่องลิงก์ปลายทาง ใส่ได้ทั้งหน้าแรกและหน้าแบบประกัน เช่น `/lifeprotect` หรือโดเมนเต็มของเว็บ
ปุ่มบนครีเอทีฟเป็น Click-to-Website ใช้ได้กับรูปเดียว วิดีโอ คารูเซล และคอลเลกชัน
คารูเซลให้ตั้งลิงก์รวมได้ และตั้งลิงก์รายการ์ดทับได้ถ้าต้องการ
วัตถุประสงค์ทราฟฟิกกับคอนเวอร์ชันใช้ปุ่มนี้เป็นค่าเริ่มต้น วัตถุประสงค์ลีดยังเลือกปุ่มนี้ได้เมื่ออยากพาไปหน้าเว็บแทนการทักเพจ
ลิงก์ว่างบันทึกไม่ได้


## ชุดของ Meta ทั้งชุด ไม่ใช่ชุดย่อยที่เราตั้งเอง

หน้า `/studio/ads` เดินตามขั้นตอนสร้างแอดของ Ads Manager โดยส่งฟิลด์จริงของ Marketing API เวอร์ชัน 23
ชนิดสี่แบบกับวัตถุประสงค์สามอย่างด้านบนคือทางที่ใช้บ่อย รายการด้านล่างคือแคตตาล็อกที่หน้านี้ต้องมีให้เลือก
ตัวเลือกที่บัญชีนี้ยังทำไม่ได้ให้เห็นแต่กดไม่ได้ พร้อมบอกว่าขาดอะไร ไม่ซ่อนแล้วแกล้งว่าไม่มีใน Meta

### วัตถุประสงค์

ใช้ชื่อผลลัพธ์ชุดปัจจุบันของ Meta ไม่ใช้ชื่อเก่าอย่าง `LINK_CLICKS`

- Awareness `OUTCOME_AWARENESS`
- Traffic `OUTCOME_TRAFFIC`
- Engagement `OUTCOME_ENGAGEMENT`
- Leads `OUTCOME_LEADS`
- App promotion `OUTCOME_APP_PROMOTION` กดไม่ได้จนกว่าจะมีแอปให้โปรโมต โปรเจกต์นี้ยังไม่มี
- Sales `OUTCOME_SALES` คือคอนเวอร์ชันบนเว็บ ต้องมี Pixel ตามแผน Conversions API

Advantage+ ของ Sales, Leads และ App คือการเปิดงบระดับแคมเปญ ผู้ชมแบบ Advantage+ และตำแหน่งแบบ Advantage+ พร้อมกัน ไม่ใช่ชนิดโฆษณาอีกแบบ ตั้งแต่เวอร์ชัน 23 ผู้ชม Advantage+ เป็นค่าเริ่มต้นของการสร้างชุดโฆษณาใหม่ และปิดได้

### รูปแบบโฆษณา

- รูปเดียว จากโปสเตอร์ใน Studio
- วิดีโอ จากคลิปที่เรนเดอร์จบ
- คารูเซล สองถึงสิบใบ จากโปสเตอร์หรือคลิป
- คอลเลกชัน ปกหนึ่งชิ้นกับรายการด้านใน
- Instant Experience สร้างผ่าน Canvas API ของเพจ จากโปสเตอร์ที่มีอยู่ คนกดแล้วอยู่ในประสบการณ์ของ Meta ก่อนไปเว็บ ถ้าเพจยังไม่พร้อมสร้างแคนวาส ตัวเลือกนี้กดไม่ได้
- แคตตาล็อกสินค้า กดไม่ได้จนกว่าจะมี product catalog ในบัญชีนี้ Studio ยังไม่มีแคตตาล็อก

### ปุ่ม

ปุ่มคือ `call_to_action.type` ของครีเอทีฟ และลิงก์อยู่ใน `value.link`
Click-to-Website ไม่ใช่รูปแบบแยก มันคือปลายทางเป็นเว็บ ปุ่มที่พาไปเว็บได้แก่ Learn More, Shop Now, Sign Up, Book Now, Download, Contact Us, Apply Now, Get Quote, Order Now, Subscribe, Watch More, See More และ Visit Website
ปุ่มที่พาไปที่อื่นยังต้องมีให้เลือกตามที่ Meta อนุญาตกับวัตถุประสงค์นั้น เช่น Message Page, WhatsApp, Call Now, Get Directions, Install App
เอกสาร Meta บอกว่าไม่ใช่ทุกปุ่มใช้กับทุกวัตถุประสงค์ได้ หน้านี้จึงแสดงรายการปุ่มของ Meta แล้วปิดตัวที่วัตถุประสงค์หรือตำแหน่งนั้นไม่รับ ไม่ได้ตัดเหลือไม่กี่ปุ่มตั้งแต่ต้น
ค่าภายในที่ไม่ได้เป็นปุ่มให้คนกด เช่น ค่าที่ใช้ภายในระบบของ Meta จะไม่โชว์

### ตำแหน่ง

ค่าเริ่มต้นคือ Advantage+ placements คือไม่ส่งตำแหน่งเอง ให้ Meta เลือกจากที่บัญชีลงได้
ถ้าเลือกเอง ส่ง `publisher_platforms` กับตำแหน่งของแต่ละที่ ได้แก่ Facebook, Instagram, Messenger, Audience Network และ Threads ตามที่บัญชีนั้นลงได้ จริง ๆ เช่น ฟีด สตอรี่ รีลส์
Stories ไม่รับปุ่ม Call Now กับ Get Directions ตามเอกสารครีเอทีฟ หน้านี้ต้องไม่ให้คู่ที่ Meta ปฏิเสธถูกบันทึก

ทุกแบบยังบันทึกเป็น PAUSED

## 2. สิทธิ์และการตรวจแอป

Config ใหม่ชื่อทำนอง Ads manage มี `ads_management` และสิทธิ์เพจที่ครีเอทีฟต้องใช้ (`pages_show_list`, `pages_read_engagement`, `pages_manage_ads`)
ไม่มีสิทธิ์ข้อความของบอทอยู่ใน config นี้

บัญชีของเจ้าของแอปเอง ใช้ Standard Access ได้โดยไม่ยื่น App Review ถ้าผู้ใช้มีบทบาทในแอปและมีสิทธิ์ในบัญชีโฆษณานั้น
ถ้าตัวแทนคนอื่นที่ไม่อยู่ใต้พอร์ตโฟลิโอนี้จะมากดสร้างเอง ต้องยืนยันธุรกิจ แล้วจึงยื่น App Review สำหรับ `ads_management`
โทเค็นผู้ใช้อายุประมาณ 60 วันเหมือนโทเค็นอ่านผล หน้านี้ต้องบอกเมื่อใกล้หมดและให้เชื่อมใหม่

ยังไม่ขอ system user ถาวรในรุ่นแรก

## 3. ใช้ชิ้นงานเดิม

โปสเตอร์ที่ Studio เรนเดอร์แล้วคือรูปของครีเอทีฟ ไม่ได้วาดใหม่
วิดีโอที่เรนเดอร์เสร็จแล้วคือไฟล์ของครีเอทีฟวิดีโอ คลิปที่ยังเรนเดอร์ไม่จบเลือกไม่ได้
ข้อความบนโปสเตอร์ไม่ถูกส่งซ้ำเป็นข้อความโฆษณา คนเขียนคำโฆษณาในฟอร์มเอง
ไอดีแอดที่ได้กลับมาเก็บคู่กับชิ้นงาน เพื่อให้หน้า `/admin/ads` ที่อ่านผลอยู่แล้วจับคู่ได้จาก `ad_id` เดิม

## สิ่งที่แผนนี้ไม่ทำ

ไม่เปิดแอดให้เองตอนบันทึก
ไม่แก้หน้าอ่านผลให้สั่งงานได้
ไม่ดึงฟอร์ม Lead Ads และไม่ยิง Pixel เพิ่มจากหน้านี้
