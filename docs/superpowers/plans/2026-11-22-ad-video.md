# วิดีโอโฆษณา Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Studio page `/studio/ad-video` where an agent picks Life Protect, iShield or iHealthy plus age/sex/sum (or plan), a small AI model writes the whole ad clip (hook, 1–3 content scenes, CTA, photo ideas) from the quote's own figures, and the existing Motion pipeline renders a 9:16 clip with AI realistic photos on the hook and closing scenes.

**Architecture:** An ad clip is a standard วิดีโอนำเสนอ Motion clip (`VideoInput`, row in `ins_quote_videos`) carrying `input.ad: AdPlan`. `make.ts` speaks the plan's lines over the scene list `lead → bodies → contact`, draws the plan's photos in `produce` like คลิปตามโจทย์'s pictures, and `Clip.tsx` swaps a photo scene's themed layer for `AdPhotoScene`. New code lives in `src/lib/ad-video/` and `src/app/studio/ad-video/`.

**Tech Stack:** Next.js App Router server actions, TypeScript, Vitest, Remotion (Cloud Run job), Supabase, `chat`/`drawImage` from `src/lib/ai/client.ts`.

**Spec:** `docs/superpowers/specs/2026-11-22-ad-video-design.md` (owner chose ก ×6; mockup https://claude.ai/artifact/ByHCizPPWBELQHcmUErCiw)

## Global Constraints

- Every figure spoken or shown comes from `quoteVideoFacts`; AI lines pass `lineProblem` with `allowedNumbers(f, note)`; failing twice → fixed line.
- AI text calls use `chat({ tier: "small", task: "ad-video-script", json: true })`, never Claude; `ad-video-script` is added to `VIDEO_SCRIPT_TASKS`.
- Photos: `drawImage({ task: "ad-video-photo", aspect: "9:16", prefer: "gemini-image" })`, painter id `"gemini"` (priced by `pictureSatang(prices, "gemini")`, ฿5 today). No Thai letters and no digits in photo prompts.
- Clip: Thai, portrait, `style: "motion"`, `length: "short"` (priced `videoMotion`), `theme` `"board"` (default) or `"navy"`, no customer name, no brief, no recipe, no riders, no budget, iHealthy one plan with no compare.
- Picture mode `art`: `"motion"` (ก), `"photo"` (ข), `"mixed"` (ค, default). Mixed = photos on `lead` and `contact` only.
- Last scene shows `DISCLAIMER` from `src/lib/content/output.ts`.
- Bodies per product: LIFEPROTECT `price`, `cover`, `value` (needs `breakEven`), `versus` (needs `totalPaid`); ISHIELD `price`, `cover`, `versus` (needs `totalPaid`); IHEALTHY `price`, `cover`. 1–3 bodies, no repeats.
- CTA keys: `chat`, `line`, `comment`, `nextyear` (only when the age+1 quote's `perDayAmount` or spoken price is higher), `meet`.
- Hook kinds: `question`, `shock`, `myth`, `story`, `list` (brief.ts `WRITTEN_HOOKS`), plus `own` (agent's line). Hook headline: 1–2 lines, each ≤ `HEADLINE_MAX` (28).
- Brief box ≤ 100 chars (`NOTE_MAX`). Draft/redraft rate limit: 60 per hour per agent, like `previewScript`.
- Feature switch key `"ad-video"`, label "วิดีโอโฆษณา", href `/studio/ad-video`; tool logo id `av`.
- Female endings in written lines; `spokenBy` turns them for a male narrator.
- Stage files by explicit path only (never `git add -A`). No push without the owner's word.

## Review Focus

1. **Agent edits a line to a wrong figure** (types "วันละ 59 บาท") → `makeAdVideo` must not speak it: `cleanAdPlan` swaps in the fixed line and the form shows the reason. Test in Task 2.
2. **Rates change between drafting and making** (draft yesterday, make today) → the plan is re-cleaned against today's facts; lines whose figures no longer match fall back. Test in Task 2.
3. **Every photo fails** (Gemini down) → clip still renders with Motion ground on those scenes and the photo money comes off the hold. Test in Task 5.
4. **AI returns keys that do not fit** (e.g. `value` for a 99-pay plan with no `breakEven`, or 4 bodies, or `nextyear` at an age where the price does not rise) → dropped/trimmed to what fits, never a crash. Test in Task 2 and Task 4.
5. **Male narrator** → lines spoken with ครับ, CTA fixed lines included. Test in Task 5.
