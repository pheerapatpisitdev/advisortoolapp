# แท็บ "ความรู้" และ "เขียนเอง" ใน Organic Studio — design

วันที่: 2026-09-29 · เจ้าของตัดสินใจทุกข้อในหัวข้อ "สิ่งที่ตกลงกัน"

## เป้าหมาย

ตอนนี้ Organic Studio มี 3 แท็บ: จากแบบประกัน · รีวิวเคลม · หาทีม — ทุกแท็บจบที่การขายหรือชวนร่วมทีม
เพิ่มอีก 2 แท็บ:

1. **ความรู้** — คอนเทนต์สร้างการรู้จักและความเชื่อใจ **ไม่ขายเลย** 3 แบบ: ความเข้าใจผิดเรื่องประกัน ·
   บทความความรู้ประกัน · คำคม/บทความดีๆ
2. **เขียนเอง** — agent พิมพ์ร่างเอง แล้ว AI เกลาออกมา 2–3 เวอร์ชันให้เลือก

สำเร็จเมื่อ: agent กดสร้างโพสต์ความรู้/คำคมได้โดยไม่ต้องเลือกแบบประกัน และเอาร่างของตัวเองมาให้ AI เกลาได้
โดยทั้งสองแท็บได้โปสเตอร์ โลโก้เพจ สูตรคอนเทนต์โปร การตรวจกฎ Facebook และลงเพจ/ปฏิทินได้เหมือนแท็บอื่น

## สิ่งที่ตกลงกัน (เจ้าของ 2026-09-29)

| เรื่อง | ตัดสินใจ |
|---|---|
| แบบในแท็บความรู้ | ความเข้าใจผิด · บทความความรู้ · คำคม/บทความดีๆ (ควิซศัพท์ไว้รอบหน้า) |
| แหล่งข้อเท็จจริง | ให้ AI ใช้ความรู้ทั่วไปได้ (ไม่บังคับอ้างคลังความรู้) |
| การขายในแท็บความรู้ | ไม่ขายเลย — ไม่เอ่ยชื่อแบบประกัน ปิดด้วยชวนเซฟ/แชร์ |
| แนวคำคม | วางแผนการเงิน/เก็บเงิน · ครอบครัว/คนที่รัก · สุขภาพ/ใช้ชีวิต · กำลังใจทั่วไป |
| เขียนเอง อยู่ที่ไหน | แท็บของตัวเอง (เรื่องอะไรก็ได้ ขายหรือไม่ขายก็ได้) |
| เขียนเอง AI ทำอะไร | เกลาให้ดีขึ้น คงใจความเดิม ออกมา 2–3 เวอร์ชัน พร้อมโปสเตอร์ |

## แนวทาง

ทำตามแบบแท็บ **หาทีม** ที่ใช้งานอยู่ (`recruit.ts` / `recruit-run.ts` / `RecruitTools.tsx` /
`/api/content-recruit`): หนึ่งชิ้นต่อหนึ่งการเรียก AI ไม่มีตัววางแผน, คลังหัวข้อฝั่งเบราว์เซอร์, แต่ละชิ้นเขียนด้วย
"มุม/โทน" ต่างกัน. ไม่แตะเส้นทาง "จากแบบประกัน" (ตัววางแผนและตัวตรวจตัวเลขของมันผูกกับข้อมูลแบบประกัน)

ทางเลือกที่ตัดไป: เพิ่ม "ไม่ผูกแบบประกัน" ในแท็บจากแบบประกัน (ต้องรื้อตัววางแผน/ตัวตรวจ เสี่ยงกระทบโพสต์ขาย) ·
ช่องหัวข้อเปล่าช่องเดียว (ไม่มีคลังให้เลือก ผลไม่สม่ำเสมอ)

## 1. แท็บความรู้

### หน้าจอ
```
แบบ:  (ความเข้าใจผิด) (บทความความรู้) (คำคม/บทความดีๆ)
หัวข้อ: [ชิปจากคลังของแบบที่เลือก] หรือ "พิมพ์เอง" (ไม่เกิน 120 ตัวอักษร)
คำคม → แนว: การเงิน / ครอบครัว / สุขภาพ / กำลังใจ  (+ พิมพ์หัวข้อเองได้)
ทำอะไร: [โพสต์] [สคริปต์]      ← ไม่มีโฆษณา (แท็บนี้ไม่ขาย)
คนอ่าน (ไม่บังคับ) · สูตรคอนเทนต์โปร · คลิปวนลูป (สคริปต์) · โลโก้ · ภาพและโมเดล · จำนวน 1–3
```

### คลังตั้งต้น (แก้/เพิ่มในโค้ดได้ภายหลัง)
- **ความเข้าใจผิด** (~10): ประกันกลุ่มบริษัทพอแล้ว · ยังหนุ่มสาวไม่ต้องรีบทำ · ซื้อตอนแก่ค่อยซื้อก็ได้ ·
  เคลมยาก บริษัทไม่จ่าย · มีเงินเก็บแล้วไม่ต้องมีประกัน · ประกันชีวิตคือเรื่องของคนตาย · ประกันสุขภาพ
  เหมาจ่ายคุ้มครองทุกอย่าง · โรคที่เป็นอยู่แล้วเคลมได้ · ทำประกันแล้วเบี้ยไม่มีวันขึ้น · ลดหย่อนภาษีได้ไม่จำกัด
- **บทความความรู้** (~10): เหมาจ่าย vs แยกค่าใช้จ่าย · ระยะรอคอยคืออะไร · OPD vs IPD · ค่าชดเชยรายวัน ·
  Co-payment/Deductible · ลดหย่อนภาษีจากประกัน · ประกันโรคร้ายแรงจ่ายตอนไหน · มูลค่าเวนคืน ·
  ทุนประกันชีวิตควรเท่าไหร่ · เตรียมเอกสารเคลม
- **คำคม**: 4 แนวตามที่ตกลง

### กติกาที่ส่งให้ AI (เพิ่มจาก `CORE_RULES` ที่ใช้อยู่แล้วทุกโหมด)
- ห้ามเอ่ยชื่อแบบประกัน ชื่อบริษัท ราคา/เบี้ย และห้ามชวนซื้อ — ปิดด้วยชวนเซฟหรือส่งต่อ (ห้าม "คอมเมนต์ว่า…"/แท็กเพื่อน)
- ความรู้ทั่วไปใช้ได้ แต่: ห้ามอ้างว่าบริษัท/กรมธรรม์ไหน "ให้หรือไม่ให้" อะไร · เงื่อนไขที่ต่างกันแต่ละกรมธรรม์ให้พูดว่า
  "ขึ้นกับเงื่อนไขกรมธรรม์" · ตัวเลขใช้ได้เฉพาะที่เป็นความรู้สาธารณะและจำเป็น (เช่น เพดานลดหย่อน) พร้อมบอกว่าเป็นของปีไหน
- ความเข้าใจผิด: บอกความเชื่อ → ทำไมคนเชื่อ → ความจริง → สิ่งที่ควรทำ (ไม่ขู่ ไม่ขายด้วยความกลัว)
- คำคม: แต่งเองเท่านั้น **ห้ามอ้างว่าเป็นคำพูดของคนดัง/บุคคลจริง** · โปสเตอร์ headline = ตัวคำคม · แคปชันสั้น 2–5 บรรทัด
- สูตรโปร/คลิปวนลูป/คนอ่าน ต่อท้ายเหมือนแท็บอื่น (`proRules`, `PRO_HOOK_RULES`, `LOOP_RULES`, `steerLines`)

### ตัวกันข้อมูลผิด
- ไม่มี "ข้อมูลผลิตภัณฑ์" เป็นไม้บรรทัด → `flagsFor(output, "", …)` ทำให้**ตัวเลขทุกตัวติดธง "ต้องตรวจ"**
  (ธงเดิมของระบบ) เจ้าของต้องยืนยันตัวเลขก่อนลงเพจ เหมือนตัวเลขนอกตารางเบี้ย
- ตัวตรวจกฎ Facebook (`policy.ts`) และคำต้องห้าม ทำงานเหมือนเดิม
- ข้อความท้ายโพสต์: `KNOWLEDGE_DISCLAIMER` = "ข้อมูลนี้เพื่อความรู้ทั่วไป เงื่อนไขจริงขึ้นอยู่กับแต่ละกรมธรรม์"
  (คำคม: ไม่มีข้อความท้าย นอกจากบรรทัดผู้รับประกันที่ระบบใส่ทุกชิ้นอยู่แล้ว — ถ้าเจ้าของไม่ต้องการบรรทัดนั้นบนคำคม บอกได้)

## 2. แท็บเขียนเอง

### หน้าจอ
```
ร่างของคุณ: [กล่องข้อความ ไม่เกิน 2,000 ตัวอักษร]
ทำอะไร: [โพสต์] [สคริปต์] [โฆษณา]
จำนวนเวอร์ชัน: 1–3
คนอ่าน · สูตรคอนเทนต์โปร · คลิปวนลูป (สคริปต์) · โลโก้ · ภาพและโมเดล
```

### AI ทำอะไร
แต่ละเวอร์ชันเกลาต่างมุมกัน (ส่งไปเป็นการเรียก AI แยกกัน):
1. **ใกล้ร่างที่สุด** — คงคำของเจ้าของมากที่สุด แก้คำผิด จัดย่อหน้า เขียน hook ใหม่
2. **กระชับ หยุดคนเลื่อน** — สั้นลง hook แรงขึ้น
3. **เล่าเป็นเรื่อง** — เรียงเป็นเรื่องเล่าอ่านลื่น

กติกา: **คงใจความและข้อเท็จจริงของร่าง ห้ามเพิ่มข้อเท็จจริง ตัวเลข หรือคำสัญญาที่ร่างไม่มี** · แก้คำที่ผิดกฎ Facebook/คำต้องห้าม ·
ร่างจะขายหรือไม่ขายก็ได้ ตามที่เจ้าของเขียน · `CORE_RULES` ใช้ครบ

### ตัวกันข้อมูลผิด
- เก็บร่างไว้ใน `output.fact` (ช่องที่มีอยู่แล้ว) → ตัวเลขที่อยู่ในร่างถือว่าอนุญาต ตัวเลขที่ AI เพิ่มเองติดธง —
  และยังได้ผลเหมือนเดิมเมื่อแก้ไขชิ้นงานทีหลัง (`saveContentEdits` ใช้ `item.output.fact` เป็นไม้บรรทัดอยู่แล้ว)
- ข้อความท้ายโพสต์: `DISCLAIMER` เดิม (+ บรรทัดภาษีเมื่อพูดถึงภาษี ตามที่ `footer()` ทำอยู่)

## ส่วนร่วมของทั้งสองแท็บ

- **ไฟล์ใหม่** (ตามแบบหาทีม): `src/lib/content/knowledge.ts` + `knowledge-run.ts` · `src/lib/content/draft.ts` + `draft-run.ts` ·
  `src/app/api/content-knowledge/route.ts` · `src/app/api/content-draft/route.ts` ·
  `src/app/studio/knowledge/KnowledgeTools.tsx` · `src/app/studio/draft/DraftTools.tsx` · action `generateKnowledge` / `generateDraft`
- **planHref** ใหม่: `"knowledge"` (ชื่อ "ความรู้") และ `"draft"` (ชื่อ "เขียนเอง") — เพิ่มในจุดที่แปลง planHref เป็นชื่อ:
  `ContentStudio.tsx` (`nameOf`, ตัวกรองรายการ) และ `calendar/page.tsx`
- **โควตา/งบ/ลิมิต**: `takeRound` (ชื่อ round ใหม่ `ai-knowledge`, `ai-draft`) · `holdContentBudget` · ลิมิตรายชั่วโมง — เหมือนหาทีม
- **โปสเตอร์ + โลโก้ + วาดภาพ + คลังบุคคล**: ใช้ของเดิมทั้งหมด (`roundLogo`, poster parse, วาดภาพหลังสร้าง)
- **แท็บบนมือถือ**: 5 แท็บในแถวเดียวแคบเกิน → ย่อชื่อเป็น "แบบประกัน · รีวิวเคลม · หาทีม · ความรู้ · เขียนเอง"
  และให้เลื่อนแนวนอนได้เมื่อจอแคบ

## การทดสอบ

- unit: prompt ของแต่ละแบบมีกติกาที่ต้องมี (ไม่ขาย / ห้ามอ้างคนดัง / คงใจความร่าง) และไม่มีเมื่อไม่ควรมี ·
  parse คำตอบ AI · planHref → ชื่อ · ตัวเลขในแท็บความรู้ติดธงทั้งหมด · ตัวเลขในร่างไม่ติดธง แต่ตัวเลขที่ AI เพิ่มติด
- route: ต้องล็อกอิน · หักโควตา · ข้อมูลผิดรูปแบบถูกปฏิเสธ
- ลองเขียนจริง (งบ AI ไม่กี่บาท): ความเข้าใจผิด 1 · บทความ 1 · คำคม 1 · เขียนเอง 3 เวอร์ชันจากร่างตัวอย่าง — แนบผลให้เจ้าของดู
