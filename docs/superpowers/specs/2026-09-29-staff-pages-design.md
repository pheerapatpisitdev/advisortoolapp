# ผูกทีมงานกับเพจ — design

วันที่: 2026-09-29 · เจ้าของอนุมัติในแชท ("ok สร้างได้เลย")

## เป้าหมาย

ทีมงานที่มีสิทธิ์ลงโพสต์ (ไม่ใช่ admin) ตอนนี้ติดอยู่ที่เพจแรก (ไม่มีหน้ารวม ไม่มีตัวสลับ) และในทางเทคนิคโพสต์ได้ทุกเพจ
ให้แต่ละคนเห็นและจัดการได้เฉพาะเพจที่เจ้าของผูกไว้

## สิ่งที่ตกลงกัน

| เรื่อง | ตัดสินใจ |
|---|---|
| เจ้าของ + ผู้มีสิทธิ์หลังบ้าน (`can_admin`) | เห็นทุกเพจ เหมือนเดิม |
| ทีมงานลงโพสต์ | เห็นเฉพาะเพจที่ผูก |
| ยังไม่ได้ผูกเพจเลย | ไม่เห็นเพจไหน (ยังเขียนงานใน Organic Studio ได้) |
| ตั้งต้น | ลักกี้ (118880) = ทั้ง 4 เพจ · เจเจ (112514) = ประกันเงินออมเพื่อลูก · Nit (117685) = ประกันเงินออมเพื่อลูก |
| หน้ารวม /studio | เปิดให้ทีมงานลงโพสต์ด้วย แสดงการ์ดเฉพาะเพจของตัวเอง |
| ใครตั้งค่า | เจ้าของ ที่หน้าทีมงาน (/admin/team) ติ๊กเพจต่อคน บันทึก audit |

## การทำงาน

- ตาราง `ins_staff_pages (agent_id → ins_staff, page_id text, primary key (agent_id, page_id))`
- `src/lib/auth/pages.ts`: `myPages()` = เพจที่เชื่อมอยู่ ∩ สิทธิ์ของผู้เรียก (admin/เจ้าของ = ทั้งหมด; ลงโพสต์ = ที่ผูก; อื่น = ไม่มี) ·
  `seesEveryPage()` — ทุกจุดที่เคยเรียก `pageConnections()` เพื่อแสดง/โพสต์ ใน Studio เปลี่ยนมาใช้ตัวนี้
- บังคับที่เซิร์ฟเวอร์: `publishSetup` · `clear()` (ทุกการโพสต์/ตั้งเวลา/ย้าย) · `withdraw()` (ยกเลิกคิว/ลบชิ้นที่ตั้งเวลาไว้) ·
  โลโก้ (`logoOwner`, `mayUseLogo`) · คลังบุคคล (หน้า + route) · Organic Studio (`StudioPage`)
- ปฏิทินและหน้ารวม: โพสต์ที่ลง/ตั้งเวลาแล้วแสดงเฉพาะของเพจตัวเอง (ชิ้นที่ไม่มีเพจแสดงให้คนที่เห็นทุกเพจเท่านั้น)
- เมนู "หน้ารวม" และโลโก้แบรนด์ Studio ชี้ไปหน้ารวมสำหรับ admin และทีมงานลงโพสต์
- ไม่เปลี่ยน: หน้าหลังบ้านเชื่อมเพจ/บอท (`/admin/messenger`, `/admin/posting`) · `verifyDue` (งานระบบ)

## การทดสอบ

unit: `myPages` ครบทุกบทบาท · `clear()` ปฏิเสธเพจที่ไม่ใช่ของตน · `withdraw()` ปฏิเสธ · โลโก้ของเพจอื่นวาดไม่ได้ · เมนู/หน้ารวมสำหรับทีมงาน ·
action ตั้งเพจของทีมงาน (เจ้าของเท่านั้น, เพจต้องเชื่อมอยู่, เจ้าของเองแก้ไม่ได้)
