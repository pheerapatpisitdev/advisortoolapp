# บอทภาษาอังกฤษสำหรับเพจ Expat (iHealthy Ultra) — design

วันที่: 2026-10-02 · เจ้าของตอบในแชท: เพจ 2 เพจ, ตอบอังกฤษ แต่ลูกค้าพิมพ์ไทยตอบไทย, ขอบเขตข้อ 1 (iHealthy Ultra อย่างเดียว), "เริ่มสร้างบทภาษาอังกฤษได้เลยเต็มรูปแบบ"

## ปัญหา

เจ้าของจะยิงแอดหาชาวต่างชาติที่เพจ **Expat Influencer Insurance** (112079600278201) และ
**Expat Insurance Thailand by Phet** (112110731809903) — ทั้งสองต่อบอทอยู่แล้ว
เทสจริง 2026-10-02 21:02 ผ่านแอด 120247308259040367: ลูกค้ากด "For more information" แล้วได้เมนูภาษาไทย
3 แผน (Life Protect / มรดก / iShield) ซึ่งไม่มี iHealthy Ultra เลย

สาเหตุ: บอททั้งตัวเป็นไทย (prompt, ข้อความตายตัว, regex อ่านอายุ/เพศ/ปุ่ม) และชื่อแอดไม่ได้บอกว่าเป็น iHealthy
ทำให้ `productFromAd` ไม่รู้แผน → ได้เมนูกลาง

## สิ่งที่ตกลงกัน

| เรื่อง | ตัดสินใจ |
|---|---|
| เพจไหน | 2 เพจข้างบน กำหนดในโค้ด (`EXPAT_PAGES`) แบบเดียวกับ `SPEAKS_AS_A_MAN` ใน `voice.ts` |
| แผน | iHealthy Ultra อย่างเดียว — ทุกแชทในเพจ Expat คือ iHealthy ไม่ว่าแอดชื่ออะไร (ไม่มีเมนูกลาง) |
| ภาษา | ค่าเริ่มต้นอังกฤษ · ข้อความมีอักษรไทย → ไทย · ข้อความไม่มีตัวอักษรบอกภาษา ("35", "👍", ปุ่ม) → ภาษาเดิมของแชท · ภาษาอื่น → อังกฤษ |
| ลูกค้าพิมพ์ไทยในเพจ Expat | ใช้บอทไทย iHealthy ตัวเดิมทั้งหมด |
| เพจไทยอื่น | ไม่เปลี่ยนอะไรเลย |
| สมัคร | **ยังไม่ส่งฟอร์มไทย/ขั้นตอนบัตรประชาชน** — บอกเป็นอังกฤษว่าตัวแทนจะดูแลการสมัครและแจ้งเอกสารในแชทนี้ แล้วเปิด lead เหมือนเดิม (รอเจ้าของยืนยันขั้นตอนสมัครของชาวต่างชาติ ค่อยเปลี่ยนเป็นขั้นตอนจริง) |
| ข้อเท็จจริง Expat (เจ้าของยืนยันแล้ว, ชุดเดียวกับ Studio) | ชาวต่างชาติที่อยู่ไทยซื้อได้ · ใช้ประกอบวีซ่าได้ (พูดกว้างๆ ห้ามระบุชื่อวีซ่า ห้ามรับประกันว่าผ่าน) · ตัวแทนดูแลเป็นภาษาอังกฤษ · ต่างประเทศ = ฉุกเฉินภายใน 90 วันของการเดินทาง ห้ามพูด "worldwide" เว้นแต่เสนอราคาอาณาเขตทั่วโลกจากตารางเบี้ย |

## โครงสร้าง (แนวทาง A: สมองภาษาอังกฤษแยก ใช้เครื่องคิดเบี้ยร่วม)

ไม่แตะสมองไทย ลดความเสี่ยงกับเพจไทยที่ทำเงินอยู่ ส่วนที่ซ้ำคือ "ลำดับการตอบ" ส่วนตัวเลขทั้งหมดมาจากที่เดียวกัน
(`iHealthyTable`, `iHealthyPricing`, `plansFor`, `cardPath`, `iHealthyQuoteText(…, WORDS.en)`, `translateFacts(…, "en")`)

### ไฟล์ใหม่

- `src/lib/assistant/expat.ts`
  - `EXPAT_PAGES` (Set ของ page id สองตัว), `isExpatPage(pageId?)`
  - `languageOf(text, previous?: "en" | "th"): "en" | "th"` — อักษรไทย → th; มีตัวอักษรละตินเป็นคำ → en; อย่างอื่น → previous ?? "en"
- `src/lib/assistant/ihealthy-en/` — สมองอังกฤษ ลำดับเดียวกับ `ihealthy/answer.ts`:
  1. stalls ("I'll think about it", "maybe later") → ตอบสั้นแล้วจบ
  2. formSent + บอกว่าส่งแล้ว → ขอบคุณ ตัวแทนจะติดต่อ
  3. อยากสมัคร ("apply", "sign up", "buy", ปุ่ม `I want to apply`) → ข้อความส่งต่อภาษาอังกฤษ, `formSent: true` (ให้ CRM นับ form_sent/lead เหมือนเดิม)
  4. ถามเรื่องบริษัท → ประโยคอังกฤษที่เขียนไว้
  5. FAQ อังกฤษ: health declaration (ห้ามบอกว่ารับ), waiting period (จาก facts), premium rises with age, monthly payment, visa (พูดกว้างๆ + ตัวแทนช่วยเช็ก), abroad (ฉุกเฉิน 90 วัน), deductible/co-pay (อธิบาย, ไม่คิดราคา)
     — ไม่มีข้อลดหย่อนภาษีแบบไทย (ถ้าถาม: ใช้ได้เฉพาะผู้เสียภาษีเงินได้ในไทย ให้ตัวแทนอธิบาย)
  6. ปุ่มเปิดแชทจากแอด / ทักทาย ("For more information", "Hi") → ทักกลับ + แนะนำ iHealthy Ultra 1 บรรทัด + ขออายุกับเพศ
  7. มีอายุ+เพศแล้ว: ขอรูป → การ์ด · ตารางเต็ม → ลิงก์ `/ihealthy-ultra?…` (หน้าเปิดเป็นอังกฤษ) · แผนอื่น · ถูกกว่า · อาณาเขต
  8. อ่าน slot (อายุ เพศ แผน อาณาเขต) ด้วย regex อังกฤษก่อน ("35", "35 years old", "male/female/man/woman/M/F", ชื่อแผนอังกฤษ, "10 million"), ใช้โมเดลเฉพาะเมื่อ regex อ่านไม่ได้ (prompt อังกฤษ คืน JSON รูปแบบเดียวกับ `HealthSlots`)
  9. ได้แผน → ใบเสนอราคา: `iHealthyQuoteText(…, WORDS.en)` + การ์ด `cardPath(…, "en")`
  10. ได้อายุ+เพศ ยังไม่มีแผน → เมนู 3 แผน (ข้อความอังกฤษ + การ์ดตารางภาษาอังกฤษ)
  11. คำถามเรื่องแผน → โมเดล (prompt อังกฤษ + facts แปลอังกฤษ + ข้อเท็จจริง Expat + กฎสุขภาพ) ผ่าน `keepGivenFigures` เหมือนเดิม
  12. นอกนั้น → small talk อังกฤษ (≤2 บรรทัด ชวนให้อายุ/เพศ)
  - ปุ่มอังกฤษ: `See other plans`, `Plan benefits`, `I want to apply`, ชื่อแผน (`Gold` ฯลฯ) — ไม่เกิน 20 ตัวอักษร
- `src/lib/assistant/ihealthy-en/words.ts` — ข้อความตายตัวทั้งหมดของสมองอังกฤษอยู่ไฟล์เดียว ให้เจ้าของแก้คำได้ง่าย

### ไฟล์ที่แก้

- `src/lib/assistant/ihealthy/route.ts` / `HealthSlots` — เพิ่ม `lang?: "en"` (ไม่มี = ไทย; แชทเดิมไม่กระทบ)
- `src/lib/assistant/dispatch.ts` — `answerAny` รับ `pageId` เพิ่ม: ถ้าเป็นเพจ Expat →
  ภาษาเป็น en → สมองอังกฤษ; เป็น th → `answerHealth` (สมองไทย) โดยตรง ข้ามเมนูกลาง/การเลือกแผน
  (คำถามประกันกลุ่มในเพจ Expat ภาษาอังกฤษ → ส่งต่อตัวแทนเป็นอังกฤษ)
- `src/lib/facebook/conversation.ts` — ส่ง `pageId` เข้า `answerAny`; ข้อความ BUSY / BROKEN / OUT_OF_BUDGET / CARD_UNSENT มีฉบับอังกฤษ เลือกตามภาษาของแชท; `spokenBy` (ครับ→ค่ะ ใน `facebook/client.ts`) ไม่ต้องแก้ — ข้อความอังกฤษไม่มีคำที่มันเปลี่ยน
- `src/app/api/ihealthy-card/table/route.tsx` — รับ `l=en` แบบเดียวกับการ์ดรายแผน (หัวตาราง ชื่อแถว จาก `translateFacts`)
- LINE / เว็บ: ไม่เปลี่ยน (ไม่มีเพจ Expat)

## ข้อมูล / CRM

ไม่มี migration — ภาษาอยู่ใน slots (jsonb) ของ session · conversation, lead, transcript, การนับ quoted/form_sent ใช้ของเดิม
ตัวแทนเห็นแชทอังกฤษใน inbox/CRM เหมือนแชทไทย

## Error

- โมเดลล่ม/หมดเวลา → ข้อความขอโทษภาษาอังกฤษ ("Sorry, something went wrong on our side — an agent will reply here shortly 🙏")
- อายุนอกช่วง / ตารางเบี้ยหมดอายุ / คิดราคาไม่ได้ → ประโยคอังกฤษ + ส่งต่อตัวแทน (ตรงกับกรณีของสมองไทย)

## ทดสอบ (vitest, mock โมเดล, ตารางเบี้ยจริง)

- `languageOf`: ไทย / อังกฤษ / "35" ตามภาษาเดิม / emoji / จีน → en
- เพจ Expat + "For more information" → ทักทายอังกฤษ ขออายุเพศ ไม่มีอักษรไทยในข้อความใดเลย
- "35 male" → เมนู 3 แผน อังกฤษ + URL การ์ดตาราง `l=en`
- "Gold" → ใบเสนอราคาอังกฤษ + การ์ด `l=en`, ตัวเลขตรงกับ `iHealthyPricing`
- "I want to apply" → ข้อความส่งต่ออังกฤษ ไม่มีลิงก์ ktaxaform, `formSent` = true
- "Can I use this for my visa?" → ไม่มีชื่อวีซ่า ไม่มีคำว่า guarantee
- ข้อความไทยในเพจ Expat → สมองไทย iHealthy (ไม่ใช่เมนูกลาง 3 แผน)
- เพจไทย + ข้อความอังกฤษ → พฤติกรรมเดิม (regression)
- ทุกข้อความของสมองอังกฤษ: ไม่มีอักษรไทย (assert ด้วย regex `[฀-๿]`)
