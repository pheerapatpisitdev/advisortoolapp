# Ads Studio — หน้าเดียวแบบ Organic Studio

สถานะ: เจ้าของเห็นตัวอย่าง (`/prototype/ads-studio`, d53c8609) แล้วสั่ง "ทำเลย" 2026-10-04
ต่อจาก [2026-10-04-ads-studio-monoko-flow-design.md](2026-10-04-ads-studio-monoko-flow-design.md)

## เป้าหมาย

Ads Studio หน้าตาและการใช้งานแบบเดียวกับ Organic Studio: หน้าเดียว สามคอลัมน์
ไม่ต้องเดินระหว่าง หน้ารายการแคมเปญ → ห้องแคมเปญ → ตัวสร้างแคมเปญ อีกแล้ว

สำเร็จเมื่อ:
- เข้า `/studio/ads` แล้วเห็นแคมเปญล่าสุดของเพจพร้อมทำงานได้ทันที
- สลับเพจ สลับแคมเปญ และสร้างแคมเปญใหม่ได้จากแผงซ้าย โดยไม่ออกจากหน้า
- ขนาด สี กรอบ แท็บ ของทั้งหน้าเหมือน Organic Studio
- ลิงก์เก่า (`/studio/ads/<id>`, `/studio/ads/new?page=`) ยังพาไปถูกที่

## ที่อยู่

ใช้อันเดียว: `/studio/ads?page=<pageId>&campaign=<id>&new=1&write=<n>`

- `campaign` ระบุแคมเปญ: เปิดแคมเปญนั้น และเพจตามแคมเปญ (ไม่สน `page`)
- ไม่มี `campaign`: เปิดแคมเปญล่าสุดของเพจ
- `new=1` หรือเพจยังไม่มีแคมเปญ: แผงซ้ายเป็นตัวสร้างแคมเปญใหม่
- `write=<1|2|4>` มาพร้อม `campaign` หลังสร้างแคมเปญ: สร้างแอดชุดแรกเอง ครั้งเดียว (เหมือนเดิม)
- `fb`, `warn`, `detail` จากการเชื่อม Facebook ยังกลับมาที่ `/studio/ads` เหมือนเดิม
- `campaign` ที่ไม่มีอยู่จริง: เปิดแบบไม่ระบุแคมเปญ; อ่านแคมเปญไม่ได้: บอกในคอลัมน์กลาง
- `/studio/ads/<id>` → `/studio/ads?campaign=<id>` (คง `write`); `/studio/ads/new?page=X` → `/studio/ads?page=X&new=1`

## โครงหน้า (ขนาดเดียวกับ Organic)

หัว: `Ads Studio · <เพจ>` คำอธิบายบรรทัดเดียว แล้วแถบบัญชีโฆษณา (ConnectBar ตัวเดิม)

Grid: `lg:[280px_1fr]`, `xl:[280px_1fr_240px]` เหมือน `ContentStudio.tsx`

**ซ้าย "เครื่องมือ"** — ติดอยู่กับที่ เลื่อนในตัวเอง มือถือพับด้วยปุ่ม "ตั้งค่าการสร้าง"
- เพจ ▾ (เมื่อมีมากกว่าหนึ่งเพจ), แคมเปญ ▾ (แคมเปญของเพจ + "+ แคมเปญใหม่…")
- เปิดแคมเปญ: การตั้งค่าแคมเปญ (CampaignSettings) ไม่มีกรอบของตัวเองแล้ว, "ลบแคมเปญนี้" ท้ายฟอร์ม,
  ปุ่มสร้าง 1/2/4 ติดก้นแผง และยังเห็นเมื่อพับบนมือถือ
- แคมเปญใหม่: ตัวสร้าง 3 ขั้น (NewCampaignWizard) ในแผง, ปุ่ม "ยกเลิก" กลับแคมเปญที่เปิดอยู่
  สร้างเสร็จ → `?campaign=<ใหม่>&write=<n>`

**กลาง "โต๊ะงาน"** — `studio-desk` กรอบเดียวกับ Organic
- แท็บปุ่มกลม ทั้งหมด · ร่าง · อนุมัติแล้ว · ส่งแล้ว · ถังขยะ พร้อมตัวเลข, ปุ่ม "ส่งขึ้น Facebook (N)" ท้ายแถว
- แถบคิว, ข้อความรอบสร้าง, การ์ดแอด `@xl:2 คอลัมน์` (`@5xl:3`)
- ตอนสร้างแคมเปญใหม่: คำแนะนำ 3 ขั้น
- ตัวแก้แอดยังเปิดเต็มจอเหมือนเดิม (ไม่อยู่ในขอบเขตรอบนี้)

**ขวา "ส่งแล้ว"** — แบบแถบ "ใช้จริง"
- จำนวนแอดที่ส่ง, รายการ: รูปย่อ, สถานะจาก Meta (กำลังวิ่ง/หยุดไว้/…), งบต่อวัน, วันที่ส่ง
- กดรายการหรือลิงก์หัวแถบ → คอลัมน์กลางไปแท็บ "ส่งแล้ว" ซึ่งเป็นที่เปิด/หยุดแอด
- ต่ำกว่า xl: อยู่ใต้แผงซ้าย (เหมือน Organic)

## ส่วนประกอบ

- `page.tsx` (server): อ่าน `adCampaignRoom` ก่อนถ้ามี `campaign`, แล้ว `adsStudioHome` ของเพจนั้น,
  เลือกแคมเปญที่เปิดด้วย `openCampaign` (ล้วน มีเทสต์), คนในภาพเหมือนห้องเดิม
- `AdsStudio.tsx` (client ใหม่): หัว + grid + แผงซ้าย (ตัวเลือกเพจ/แคมเปญ) ส่งต่อให้
  `CampaignRoom` (เปิดแคมเปญ) หรือ `NewCampaignWizard` (แคมเปญใหม่)
- `CampaignRoom.tsx`: เลิกวาดหัวของตัวเอง วาดสามคอลัมน์โดยรับ "ส่วนบนของแผงซ้าย" จาก AdsStudio
- `SentRail.tsx` (ใหม่) + `sentRows` ใน `src/lib/ads/sent-view.ts` (ล้วน มีเทสต์)
- `CampaignList.tsx` เลิกใช้: ปุ่มลบย้ายเข้า CampaignSettings, ขั้นตอน 3 ขั้นย้ายเข้าคอลัมน์กลาง
- ฝั่ง server actions ไม่เปลี่ยน
