# Ads Studio แบบ Monoko — วิซาร์ด มิติ คิว และส่งเป็นชุด

สถานะ: spec รอเจ้าของตรวจ ยังไม่เขียนโค้ด
ต่อจาก [2026-10-04-ads-studio-campaigns-design.md](2026-10-04-ads-studio-campaigns-design.md) ซึ่งขึ้นโปรดักชันแล้ว
อ้างอิงขั้นตอนของ Monoko AD Studio (แบรนด์ luckyplanner) ที่ดูเมื่อ 2026-10-04

## เป้าหมาย

ให้ Ads Studio เดินแบบ Monoko ซึ่งเจ้าของมองว่าง่ายกว่า:
สร้างแคมเปญผ่านวิซาร์ด → AI ออกแบบ 4 มิติ → สร้างแอดจากคิวครั้งละไม่กี่ชิ้นพร้อมรูป → อนุมัติหรือทิ้งบนการ์ด → ส่งทุกชิ้นที่อนุมัติขึ้น Facebook ครั้งเดียว
ยังเป็นของเจ้าของ (รหัส 015495) คนเดียว ยิงได้ทุกเพจที่เชื่อม

สำเร็จเมื่อ:
- สร้างแคมเปญได้ใน 3 ขั้นโดยไม่ต้องตั้งจำนวนมุม × โทนเอง
- กดสร้าง 1 / 2 / 4 ชิ้นแล้วได้แอดพร้อมรูปตามสไตล์ภาพ
- อนุมัติหลายชิ้นแล้วกดส่งครั้งเดียว ได้ 1 แคมเปญ + 1 ชุดโฆษณา + N แอด บน Meta เป็น PAUSED
- เปิดใช้หรือหยุดทั้งชุดได้ด้วยการยืนยันหนึ่งครั้ง

## ขอบเขต

มี
- วิซาร์ด `/studio/ads/new` 3 ขั้น, การวิเคราะห์มิติด้วย AI, 4 มิติ (ฮุก × กลุ่มคน × มุมขาย × สไตล์ภาพ)
- คิวสร้าง 1 / 2 / 4 ชิ้นต่อครั้ง วาดรูปอัตโนมัติทุกชิ้น
- อนุมัติ / ทิ้ง บนการ์ด, แท็บ ทั้งหมด / ร่าง / อนุมัติแล้ว / ส่งแล้ว / ถังขยะ
- ส่งเป็นชุด (ตาราง `ins_ad_send`, `ins_ad_send_item`), เปิดใช้ / หยุด ทั้งชุด

ไม่มี
- วางข้อความสินค้าเองหรือดึงจาก URL — ข้อมูลสินค้ามาจากแบบประกันในระบบเสมอ (ตัวเลขจากตารางอัตรา)
- อัปโหลดรูปอ้างอิง, carousel, อัตราส่วนอื่นนอกจาก 1:1, AD Pilot
- ให้ AI เลือกคู่ที่ดีที่สุดแทนการเดินคิว

## 1. วิซาร์ดสร้างแคมเปญ `/studio/ads/new?page=…`

แถบบอกขั้นด้านบน ย้อนกลับได้ทุกขั้น

ขั้น 1 ข้อมูลแคมเปญ
- เพจ (เลือกไว้จากหน้าที่กดมา), แบบประกันจากรายการในระบบ
- ชื่อ (ไม่บังคับ, ≤60), สิ่งที่อยากเน้น (ไม่บังคับ, ≤120), น้ำเสียงแบรนด์ (ไม่บังคับ, ≤120), โทนสีโปสเตอร์

ขั้น 2 วิเคราะห์ด้วย AI
- AI หนึ่งรอบอ่านข้อมูลแบบประกัน + สิ่งที่อยากเน้น + น้ำเสียง แล้วเสนอ ฮุก 8–12, กลุ่มคน 3–5, มุมขาย 3–5, สไตล์ภาพ 3–5 (แต่ละข้อสั้น มีคำอธิบายหนึ่งบรรทัด)
- ราว 10–20 วินาที ค่าใช้จ่ายไม่ถึง 1 บาท กันงบด้วยระบบเดิม
- AI ล้ม → ใช้รายการตั้งต้น (มุมขายจาก `ANGLE_BANK`, กลุ่มคนและสไตล์ชุดตายตัว, ฮุกจากคลังสูตรประโยคเปิด) ขั้นนี้ไม่ค้าง

ขั้น 3 มิติและสร้าง
- 4 รายการ ติ๊กออก แก้ข้อความ เพิ่มเองได้ (แต่ละมิติต้องเหลืออย่างน้อย 1)
- แสดงจำนวนแบบทั้งหมด เช่น "10 × 4 × 4 × 4 = 640 แบบ"
- เลือกจำนวนชิ้นแรก 1 / 2 / 4 แล้วกด **สร้างแคมเปญ** → บันทึก → เข้าห้อง → เริ่มสร้างชุดแรก

## 2. ห้องแคมเปญ และคิวสร้าง `/studio/ads/[id]`

ซ้าย แผงตั้งค่า (พับได้)
- ข้อมูลแคมเปญ (แบบประกันอ่านอย่างเดียว), 4 มิติแก้ได้ — มีผลกับชิ้นที่ยังไม่ได้สร้างเท่านั้น
- ปุ่ม **สร้าง N โฆษณา** (1 / 2 / 4) ติดล่างแผง บอกค่าใช้จ่ายโดยประมาณ ปิดระหว่างสร้าง
- แคมเปญที่ยังไม่มีมิติ (ของเก่า) แสดงปุ่ม **ให้ AI วิเคราะห์มิติ** แทน

ขวา บนสุด แถบคิว
- "พร้อมสร้าง · คิวถัดไป: <ฮุก> × <กลุ่มคน> × <มุมขาย> × <สไตล์ภาพ>" และตัวนับ "สร้างแล้ว / ทั้งหมด"
- ลำดับคิว: ไม่ซ้ำแบบเดิม ครอบคลุมทุกแบบเมื่อเดินจนสุด และชิ้นที่ติดกันต่างกันหลายมิติที่สุด (ไม่ใช่ 1-1-1-1, 1-1-1-2)
- แก้มิติแล้วคิวคิดใหม่จากมิติปัจจุบัน ข้ามแบบที่สร้างไปแล้ว

สร้างหนึ่งชิ้น
- เขียนคำโฆษณาหนึ่งรอบตามแบบ (ตัวเขียนเดิม `writeAds` รับแบบหนึ่งชุด ตัวเลขจากตารางอัตรา เช็กกฎ Facebook เหมือนเดิม)
- วาดรูปพื้นหลังด้วยตัววาดเดิม โดยใช้สไตล์ภาพเป็นคำสั่งวาด (ตัววาดมาตรฐาน)
- การ์ดขึ้นเป็นโครงรอแล้วเติมเมื่อเสร็จ ชิ้นที่พังขึ้นแดงพร้อมปุ่มลองใหม่ ชิ้นอื่นไม่สะดุด

การ์ด
- แท็บ **ทั้งหมด / ร่าง / อนุมัติแล้ว / ส่งแล้ว / ถังขยะ** พร้อมตัวนับ
- โปสเตอร์ 1:1, ป้าย 4 มิติ, ป้ายเตือนกฎ Facebook, ปุ่ม **✓ อนุมัติ** และ **✕ ทิ้ง** บนการ์ด (ชิ้นที่ส่งแล้วไม่มีสองปุ่มนี้)
- กดการ์ดเปิดหน้าแก้เดิม (แก้คำ วาดใหม่ ตัวอย่างฟีด) ไม่มีส่วนยิงแอดแล้ว

## 3. ส่งขึ้น Facebook

ปุ่ม **ส่งขึ้น Facebook (N)** ที่หัวห้อง — N = อนุมัติแล้วและยังไม่ได้ส่ง; ปิดเมื่อ N = 0 หรือยังไม่ได้เชื่อมบัญชีโฆษณา หรือยังไม่ได้ตั้ง `META_TH_VERIFIED_IDENTITY_ID`

หน้าต่างส่ง
- บัญชีโฆษณา (สกุลบาทเท่านั้น), ลิงก์ปลายทาง (ใส่หน้าแบบประกันของแคมเปญไว้ก่อน แก้ได้), งบต่อวัน (เพดาน `ADS_MAX_DAILY_BUDGET_THB`)
- รูปย่อของทุกชิ้นที่จะส่ง เอาออกได้
- กด **สร้างเป็นแอดหยุดไว้**

บน Meta (PAUSED ทั้งหมด)
- แคมเปญ 1 + ชุดโฆษณา 1 (ไทย อายุ 20+, Advantage+ audience, THAILAND_UNIVERSAL + ตัวตนที่ยืนยันแล้ว)
- ต่อชิ้น: อัปโหลดรูป → ครีเอทีฟ (Click-to-Website) → แอด
- ความคืบหน้าทีละชิ้น ชิ้นที่พังไม่หยุดชิ้นอื่น ลองใหม่ทำเฉพาะที่ขาด ไม่สร้างแคมเปญ/ชุดโฆษณาซ้ำ กันกดซ้ำด้วย claim แบบเดิม

แท็บ ส่งแล้ว
- จัดกลุ่มตามรอบส่ง: บัญชี งบ สถานะจาก Meta และสถานะแต่ละแอด
- **เปิดใช้ทั้งชุด** (ยืนยัน: บัญชี เพจ งบต่อวัน) เปิด แคมเปญ → ชุดโฆษณา → ทุกแอด; **หยุดทั้งชุด** หยุดแคมเปญ
- แก้ชิ้นที่ส่งแล้วไม่เปลี่ยนแอดบน Meta หน้าแก้บอกชัด
- แอดที่ยิงด้วยระบบเดิม (`ins_ad_launch`, แคมเปญ `120253679414150653`) แสดงในแท็บนี้ เปิดใช้ / หยุด ได้

## 4. ข้อมูล การย้าย เงิน และการทดสอบ

ข้อมูล
- `ins_ad_campaign` เพิ่ม `dimensions jsonb` (`{ hooks, personas, angles, styles }` แต่ละรายการเป็น `{ text, note }`), `queue_pos int`, `brand_voice text`; `angles`/`tones` เลิกใช้ ไม่ลบ
- ชิ้นแอด `output.ad` = `{ hook, persona, angle, style, combo }` (combo = ดัชนีในคิว)
- อนุมัติ = `status 'used'`, ร่าง = `draft`, ทิ้ง = `trashed`
- `ins_ad_send`: campaign (Studio), act_id, page_id, link, currency, daily_budget_minor, meta campaign_id, adset_id, step, error, claimed_at, activated_at, paused_at, created_by, created_at
- `ins_ad_send_item`: send_id, piece_id, image_hash, creative_id, ad_id, error; unique (send_id, piece_id); ชิ้นหนึ่งอยู่ได้ในรอบส่งเดียวที่ยังไม่ถูกเลิก
- RLS + service_role แบบตารางอื่น

ย้ายของเดิม
- แคมเปญเดิมไม่มีมิติ → ปุ่มวิเคราะห์มิติในห้อง
- ชิ้นแอดเดิมอยู่ในแท็บตามสถานะ; ชิ้นที่มีแถว `ins_ad_launch` ถือเป็น "ส่งแล้ว"

เงิน
- ต่อชิ้น: เขียนราว 0.1–0.5 บาท + วาดราว 0.43 บาท; วิเคราะห์มิติต่อครั้งไม่ถึง 1 บาท
- กันงบก่อนทุกครั้งด้วย `holdContentBudget`; เพดานเต็มบอกก่อน ไม่สร้างครึ่งๆ
- เพดานค่า AI ต่อเดือนของเจ้าของค่าเริ่มต้น 30 บาท (≈30–40 ชิ้น) ปรับที่ `/admin/ai`
- การส่งไม่มีค่า AI; เงินโฆษณาเริ่มเมื่อกดเปิดใช้เท่านั้น

ทดสอบ
- unit: ลำดับคิว (ไม่ซ้ำ ครอบคลุม ต่างกัน), อ่านผลวิเคราะห์ + รายการตั้งต้น, สร้างหนึ่งชิ้นตามแบบ, อนุมัติ/ทิ้ง, ส่งเป็นชุด (PAUSED, ชิ้นพังไม่หยุดชิ้นอื่น, ลองใหม่ไม่ซ้ำ, กันกดซ้ำ), เปิดใช้/หยุดทั้งชุด, ทุก action เฉพาะเจ้าของ
- เบราว์เซอร์: localhost ด้วยบัญชีเจ้าของ ห้ามกดวิเคราะห์ สร้าง หรือส่ง โดยไม่ถามเจ้าของ (เงินจริง, ฐานโปรดักชัน)
- โปรดักชัน: migration ก่อน แล้ว push
